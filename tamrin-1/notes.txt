تمرین ۱ - کلاس Claude Coding
============================

موضوع: اتصال گیت‌هاب به Claude

مراحل انجام‌شده:
۱. ثبت‌نام در GitHub
۲. ساخت ریپازیتوری عمومی (Public) به نام My-first
۳. اتصال ریپازیتوری به Claude از طریق MCP
۴. ساخت یک پوشه و یک فایل متنی داخل آن
۵. قرار دادن محتوای پوشه در ریپازیتوری با Commit و Push توسط Claude

چیزهایی که یاد گرفتم:
- Git ابزاری برای نگه‌داشتن تاریخچهٔ تغییرات فایل‌هاست.
- Commit یعنی ثبت یک نسخه از تغییرات.
- Push یعنی فرستادن کامیت‌ها به گیت‌هاب.
- MCP راهی است که Claude با آن به ابزارهایی مثل گیت‌هاب وصل می‌شود.
